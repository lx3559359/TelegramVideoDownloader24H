Telegram 视频自动下载器 v0.3.7 · Windows x64 独立安装版

本安装包已包含 Python、Tk 和所需依赖，不需要额外安装运行环境。
支持 Windows 10 / 11 64 位。无需管理员权限，建议保留默认安装目录。

首次使用：
1. 从 my.telegram.org 获取你自己的 API ID 和 API Hash，在“账号”页填写。
2. 使用 Telegram 扫码或手机号登录，选择你有权访问的群组/频道。
3. 在“运行”页选择保存目录并启动后台。首次授权联网验证可开通 24 小时试用，后续使用需要有效授权。

工具仍需正常访问 Telegram 的网络条件；打包不会改变网络或账号权限。
关闭窗口会隐藏到托盘。安装更新或卸载前，请先停止后台，并从托盘退出程序。
更新请通过官网下载新版安装包，安装到同一目录。安装版不使用 Git 源码更新。

配置、账号会话、队列与日志保存在安装目录；视频存入你选择的目录。
更新与卸载默认保留使用中产生的配置和下载文件。请不要分享会话文件。
本安装包不含开发者账号、API 密钥、服务器密码或私人视频。

第三方组件：Python、Tcl/Tk、Telethon、cryptg、Pillow、pystray、qrcode、tzdata 等。
本软件使用 PyInstaller 打包及 Inno Setup 安装器；相关许可证位于随包依赖的元数据中。
本安装包尚未进行发行者代码签名。请仅从官方网站下载并核对 SHA-256 校验值。
