# 配置器可视化下载进度条设计

## 背景与目标

“运行”页目前以文字显示当前文件、已下载/总字节、百分比、速度和断点状态。托盘悬停也会显示简要进度，但页面缺少一眼可见的进度条。

本功能在不增加后台采样、网络请求或常驻线程的前提下，为当前下载增加横向可视化进度条。

## 界面行为

在“运行”页当前文件信息下增加 `ttk.Progressbar` 和百分比状态文字：

- 总大小已知且存在当前下载时，使用确定模式展示 `0–100%`。
- 百分比限制在 `0–100`，畸形、负数、非有限值或错误类型不传给 Tk 控件。
- 没有当前任务时归零并显示“等待任务”。
- 有任务但总大小或百分比暂不可用时归零并显示“正在准备”。
- 状态为停止、需要登录、配置错误、后台错误或心跳异常时停止变化，由现有状态和错误区域解释原因。
- 已下载/总大小、平均速度和是否断点续传的现有文字继续保留。

进度条不承担多任务总进度，也不增加历史队列整体百分比；它只表示当前文件。

## 数据流与性能

进度条复用 `DownloaderApp._refresh_status()` 每 2 秒读取的同一份心跳快照。更新顺序为：验证快照、更新文字、更新进度条、向托盘发布同一快照。

不增加：

- 新的状态轮询器。
- 高频动画定时器。
- 下载服务中的 UI 代码。
- 配置器隐藏后的额外刷新频率。

因此下载服务的 CPU、内存、磁盘和网络行为不变。配置器关闭到托盘后仍保持原有 2 秒状态读取，用于托盘标题更新。

## 错误处理

进度格式化继续使用无副作用的纯函数。缺失或畸形字段降级为安全文本和零值，不得使 Tk 刷新回调停止。状态监听器错误不能破坏页面控件更新。

## 测试与验收

- 0%、中间值、100% 对应正确进度值和百分比文字。
- 无任务、未知总大小、缺失字段、字符串、负数、NaN 和无穷值安全降级。
- 停止、心跳异常和错误状态不会运行进度动画。
- 页面文字、进度条和托盘展示来自同一快照。
- 状态刷新仍为 2 秒，不创建额外线程或轮询回调。
- Windows 实机下载时，进度条与心跳字节和托盘百分比一致。
